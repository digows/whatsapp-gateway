# WhatsApp Gateway 3.0.2

The published contracts and Chat Adapter now resolve their development exports
to compiled JavaScript, including the Mastra example. Previously these exports
pointed to source files absent from the release archives, which prevented value
imports in consumers selecting the development condition.

Workspace tests retain their source exports. The release gate validates every
announced export condition against the compiled files in the archive. Installed
consumer checks import the real contracts, Adapter and Mastra example with both
default and development conditions before opening services.

All four manifests share 3.0.2. Wire API 1, SQL schema 9 and gateway runtime
behavior are unchanged. Publication and deployment remain separate operations.

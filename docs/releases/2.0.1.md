# WhatsApp Gateway 2.0.1

This patch adds native AMD64 container publication and supports Redis 8.10.2
without changing the wire API or database schema.

- Run the complete configured checks on native AMD64 and ARM64 with both
  Redis 8.2.10 and 8.10.2.
- Require Redis 8.2 or later within 8.x, preserving the AOF and `noeviction`
  guards and rejecting older, unsupported-major and malformed server versions.
- Smoke-test each image on a matching Docker host before publishing it. Verify
  image/runtime architecture, version, revision, storage, readiness and restart.
- Assemble shared version/SHA/major/latest tags from the two qualified immutable
  image digests, preserving the original 2.0.0 tag, release and assets.

The gateway remains independent of Mastra and Chat SDK at runtime. Their adapter
continues to run in the consumer application over the existing HTTP or Redis
Streams contracts. Qualification uses isolated fixtures without live WhatsApp
accounts, external model calls or production Redis configuration changes.

The workflow receipt records the actual source, platforms, Redis versions and
published digests. This release does not claim production deployment or real
channel acceptance; the existing native consumer replay limits still apply.

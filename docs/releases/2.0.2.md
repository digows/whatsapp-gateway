# WhatsApp Gateway 2.0.2

This patch makes the consumer packages installable from the versioned GitHub
Release archives with pnpm 12.9.1 dependency protections enabled.

The Chat Adapter requires the exact matching contracts version as a mandatory
peer. Consumers provide both verified tarballs directly; no transitive URL
override or npm publication is required. Release checks reject missing, ranged,
optional or regular contracts dependencies in the packed Adapter.

The installed-package test serves the compiled tarballs over HTTP, installs them
with `blockExoticSubdeps: true` and no overrides, and exercises native Mastra
channels with a controlled model. It checks completed-event deduplication,
stable-key posting and rejection of conflicting payloads.

All four package manifests share version 2.0.2. Gateway runtime behavior, wire
API1 and SQL schema9 are unchanged. This patch does not require replacing an
existing 2.0.1 deployment, and does not claim real WhatsApp channel acceptance.
The release workflow retains the existing native image qualification and
publication gates.

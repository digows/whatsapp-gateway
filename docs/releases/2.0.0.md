# WhatsApp Gateway 2.0.0

A standalone, multi-account WhatsApp gateway for AI agents and agent frameworks.

This release establishes synchronized SemVer for the repository, runtime,
portable contracts and Chat SDK Adapter. It adds annotated-tag releases,
versioned consumer archives with SHA-256 checksums, and versioned container
images with source revision and version labels.

The runtime retains durable explicit-key send operations, UNKNOWN/conflict
handling, pacing and bounded typing, on-demand media, HTTP and Redis transports,
PostgreSQL workspace isolation and local SQLite databases per workspace.

The wire protocol remains `apiVersion: "1"`; the SQL schema remains 9. Package
SemVer does not select a protocol or storage migration. The qualified image
platform is Linux/ARM64 only. GHCR aliases are `2.0.0`, `2` and `latest`, alongside
the source SHA tag and immutable digest reported below.

Consumer assets are `digows-whatsapp-gateway-contracts-2.0.0.tgz`,
`digows-chat-adapter-whatsapp-gateway-2.0.0.tgz` and `SHA256SUMS`. Verify checksums
before installing both local archives. No npm registry publication is included.

The Adapter retains its qualified Chat 4.43.0 and optional Mastra core 1.79.0
profile. Native fresh-key replies and swallowed model errors do not become
durable consumer execution guarantees. The proposed public Mastra durable
binding remains incomplete: measured generic-workflow ownership and durable
Agent terminal-retention limits are documented in the owning gateway use case.
This version does not implement another consumer binding or a framework patch.
